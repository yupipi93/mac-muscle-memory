What these shortcuts took away

  • Terminals: Ctrl+C copies instead of interrupting, so stop a running command with Ctrl+\. Ctrl+Z undoes instead of suspending. Ctrl+A selects all instead of jumping to the line start, so use ⌘ Cmd+← or Home.
  • Cmd+Shift+3 now opens the crop tool too, because that is what the Print Screen key sends. A full-screen shot to the clipboard is still Ctrl+⌘ Cmd+⇧ Shift+3.
  • Ctrl+Cmd+←/→ belongs to the system now, so apps that used it (moving an editor between groups in Cursor, for example) no longer get it.
