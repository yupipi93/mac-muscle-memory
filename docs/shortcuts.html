What Ctrl no longer does

  • In terminals Ctrl+C copies instead of interrupting, so stop a command with ⌃ Ctrl+\. Ctrl+Z undoes instead of suspending, Ctrl+B no longer reaches tmux, and Ctrl+A selects all instead of jumping to the line start: use ⌘CmdAlt+←.
  • Cmd+Shift+3 opens the crop tool too, because that is what the Print Screen key sends. Full screen to the clipboard is still ⌃ Ctrl+⌘CmdAlt+⇧ Shift+3.
  • Ctrl+Cmd+←/→ belongs to the system now, so apps that used it (moving an editor between groups in Cursor, for example) no longer get it.
